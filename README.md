# Minecraft-Chemistry
A mod about chemistry in Minecraft.

This Mod adds many chemical things into Minecraft,\
such as some elements like Silver, or some compounds like CO2 and so on.

It was developed and kept by a student in Grade 9, so may be a few mistakes in this mod, and I don't have any website,\
so if you found some mistakes, or you have some good ideas, please make issues to tell me.
